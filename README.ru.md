# ADMON395 Public-Safe Evidence Kit

**Краткий путеводитель по проекту · EN / RU**

Воспроизводимый пакет материалов для чтения и проверки страницы результатов поиска форума, связанной с учётной записью admon395. Здесь собраны подготовленные для публикации исходные материалы, хеши, скрипты анализа, документы для читателя и матрица доказательств.

Пакет описывает предоставленный снимок источника. Хеши связывают запись с конкретными байтами; сами по себе они не устанавливают авторство, историческую полноту или достоверность каждого утверждения источника.

Этот путеводитель составлен и отредактирован вручную по проверенному источнику. Исходная техническая документация остаётся справочным материалом для команд, требований сборки, точных версий и подробных проверок.
