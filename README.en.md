# ADMON395 Public-Safe Evidence Kit

**Concise project guide · EN / RU**

A reproducible reading and evidence package for the account-bound forum search page admon395. The repository brings together public-safe source material, hashes, analysis scripts, reader-facing documents and a proof matrix.

The package documents the supplied source snapshot. Hashes bind the recorded bytes; they do not by themselves establish authorship, historical completeness or the truth of every statement in the source.

This manually edited guide summarizes the audited source. The original technical documentation remains the reference for commands, build requirements, exact versions and detailed evidence.
